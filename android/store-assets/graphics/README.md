# Graphics Checklist

This folder is for exported store graphics.

## Required Files

- `app-icon-play-512.png`
  - Size: 512 x 512
  - Format: PNG
  - Purpose: Play listing app icon

- Adaptive launcher icon source
  - Foreground and background sized for Android adaptive icon usage
  - Keep key artwork within the safe masked area
  - Purpose: launcher icon consistency across Android devices

- `feature-graphic-v1.png`
  - Size: 1024 x 500
  - Format: PNG or JPG
  - Purpose: Play Store feature graphic

## Design Guidance

- Match the app branding used in the Android launcher icon.
- Keep text minimal or avoid text entirely.
- Ensure strong contrast at small sizes.
- Avoid clutter and tiny details.
- Keep the visual tone calm and trustworthy.
- Verify the adaptive icon still reads clearly when masked to circle, squircle,
  and rounded-square launcher shapes.

## Export Checklist

- Correct dimensions
- No transparency issues
- No pixelation
- Consistent background treatment
- Reviewed on both light and dark Play Console previews
