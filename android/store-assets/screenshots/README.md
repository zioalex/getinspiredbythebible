# Screenshot Checklist

This folder is for exported Play Store screenshots.

## Recommended Initial Set

Capture screenshots from the native Android app, not from the web frontend.

Recommended baseline phone size:

- 1080 x 1920 portrait or another Play-accepted phone resolution used
  consistently across the set

- `phone-en-01-welcome.png`
  - Welcome or landing state

- `phone-en-02-chat.png`
  - Active chat with encouragement response

- `phone-en-03-verses.png`
  - Verse references expanded

- `phone-en-04-language.png`
  - Language or localization example

- `phone-ar-01-rtl-chat.png`
  - Arabic RTL example

## Capture Guidance

- Use the production or staging backend, not broken local states.
- Avoid placeholder or error content.
- Use realistic, respectful prompts and responses.
- Keep status bar noise minimal if possible.
- Keep screenshots consistent in spacing, theme, and typography.

## QA Checklist

- Correct device frame or no frame, consistently
- No debug labels or localhost URLs
- No clipped text
- No typo in UI copy
- No personal data in screenshots
- Files named consistently
