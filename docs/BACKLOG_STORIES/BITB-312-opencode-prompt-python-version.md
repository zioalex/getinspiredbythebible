# BITB-312: opencode Agent Prompts Still Say "Python 3.12"

**Status:** 🎯 Todo
**Priority:** P3
**Size:** XS
**Created:** 2026-11-13
**Prompted by:** BITB-304 follow-up.

## Problem

BITB-304 moved the backend, CI and docs to Python 3.14 (`.python-version`). The agent
prompt text generated by `scripts/generate-opencode-config.py` and committed in
`opencode.json` still describes the stack as "Python 3.12 / FastAPI". BITB-304 left that text
alone on purpose, because changing those files needs the opencode live-config gate
(BITB-280), which can't run in the build sandbox.

## Requirements

1. Change the version in the generator prompt text and regenerate `opencode.json`.
   Better still, derive it from `.python-version` so it can't drift again.
2. Pass `make test-opencode-config-live` and `make test-opencode-config-live-selftest`
   before pushing.

## Acceptance criteria

- [ ] No "Python 3.12" left in `opencode.json` or the generator
- [ ] Live-config gate green
