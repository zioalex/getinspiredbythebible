# BITB-220: Independent Audit of Every Makefile Target

**Status:** � In Review — PR #1196
**Priority:** P2
**Size:** L
**Created:** 2026-10-23

**As a** maintainer, **I want** every `make` target audited, classified by blast radius and
exercised against recording fakes,
**so that** the Makefile's documented behaviour matches what the targets do, and no target
silently reports success on failure or touches live systems unexpectedly.

## Spec

- Cover all targets in the root `Makefile` (128 counted, including hidden helpers and the
  two `.env.*` file rules); none may be left unclassified.
- Audit and validation are static or mocked only: nothing in the audit contacts Azure,
  Docker, Kubernetes, Terraform state, package indexes or any live service, and nothing is
  deployed or installed.
- The audit must be reproducible from the repo: a generator, a classification file, a
  generated report and offline tests, wired to one `make test-makefile` target.
- Out of scope: running targets live against production or cloud accounts.

## Implementation (pending PR)

- `scripts/audit_make_targets.py` inventories targets from `make -pRrq`, dry-runs each with
  `make -n`, enforces the classification invariants, scans docs and workflows for
  references to missing targets, and writes or checks `docs/MAKE_TARGET_AUDIT.md`.
- `scripts/make_target_audit.json` classifies each target (8 safety classes; execution
  `real` / `mocked` / `static`, with covering tests or a `blocked_reason`) and records the
  defects and open findings.
- `scripts/test_make_targets.py` (80 offline unit tests) runs recipes in a sandbox whose
  `az`, `docker`, `kubectl`, `terraform`, `curl`, `gradlew`, `pip` and `detect-secrets` are
  recording fakes.
- `Makefile` fixes for D1-D13 plus a `test-makefile` target; matching doc corrections in
  `AGENTS.md`, `opencode.json`, `.opencode/agents/verifier.md`, `android/COMPOSE_TESTS.md`,
  `deployment/README.md` and `deployment/scripts/import-existing-resources.sh`.
- The generated report is lint-clean for the repo's hooks (one trailing newline, no bare
  URLs, no padded code spans); `scripts/test_make_targets.py` asserts this.

## Results (static and mocked evidence only; no live claims)

- Targets: 128, all dry-run clean with `make -n`.
- Executed: real 0, mocked 116, static 12 (each static target carries a `blocked_reason`).
- Defects found and fixed: 13 (D1-D13), each with a named regression test.
- Open findings, documented and not fixed: 3 (O1-O3).
