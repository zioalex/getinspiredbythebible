## How to reproduce

```bash
make test-makefile                                  # unit tests (fake az/docker/kubectl/terraform/gradle) + freshness check
python3 scripts/audit_make_targets.py --check        # invariants + this report is current
python3 scripts/audit_make_targets.py --list         # raw inventory from `make -pRrq`
python3 scripts/audit_make_targets.py --write        # regenerate this file
```

Every target is dry-run with `make -n` (no recipe executes). *Executed* says how the recipe itself was exercised: **real** = run for real during the audit on a machine with the shared venv; **mocked** = run by `scripts/test_make_targets.py` in a sandbox whose `az`, `docker`, `kubectl`, `terraform`, `curl`, `gradlew`, `pip` and `detect-secrets` are recording fakes; **static** = dry-run only, with the reason it could not be executed.
