Methodology:
  • One unit of work = one first-parent commit on main (squash-merged PR, merge commit, or direct commit); release-please version bumps excluded.
  • Line counts exclude generated files (lockfiles, CHANGELOG) and data/; docs counted separately.
  • Regression fix = fix ≤7 days after a feat sharing scope or a code file — a proxy, not a verdict.
  • Regenerate with make repo-metrics.
  • Audit trend dashboard: ./audit/ on the published site (repo: docs/audits/metrics/).
